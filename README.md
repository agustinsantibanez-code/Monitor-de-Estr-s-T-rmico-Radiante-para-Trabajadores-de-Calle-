# Monitor de estrés térmico radiante para trabajadores de Calle
Dispositivo Low-Tech para medir el estrés térmico en trabajadores de la vía pública. Mediante un sensor de globo artesanal, alcula la radiación térmica real del asfalto y la humedad. Su interfaz física alerta sobre riesgos de golpe de calor sin depender de teléfonos inteligentes.
